# Railway Company API System

## Overview

Backend system for African railway companies to register, get API keys, and integrate their stations with the Africa Railways platform.

## Components Created

### 1. Database Schema (`database-railway-api-schema.sql`)

**Tables:**
- `railway_companies` - Railway company registrations
- `railway_stations` - Stations managed by companies
- `railway_company_routes` - Routes operated by companies
- `railway_api_logs` - API usage tracking
- `railway_api_rate_limits` - Rate limiting per company

**Features:**
- Auto-generation of API keys on approval
- Row Level Security (RLS) policies
- Admin approval workflow
- Sample data for 5 African railway companies

**Sample Companies Seeded:**
1. Kenya Railways Corporation (approved)
2. TAZARA Railway - Tanzania (approved)
3. Zambia Railways (approved)
4. South African Rail Commuter Corporation (pending)
5. Nigerian Railway Corporation (pending)

### 2. Supabase Edge Functions

#### `railway-api-register`
- Endpoint for railway companies to register
- Validates company information
- Creates pending registration
- Sends notification to admins

**Usage:**
```bash
POST /functions/v1/railway-api-register
Content-Type: application/json

{
  "company_name": "Kenya Railways Corporation",
  "country": "Kenya",
  "contact_email": "api@krc.co.ke",
  "contact_phone": "+254-20-221211",
  "website": "https://www.krc.co.ke"
}
```

#### `railway-station-register`
- Endpoint for approved companies to register stations
- Requires API key authentication
- Validates station data
- Logs API usage

**Usage:**
```bash
POST /functions/v1/railway-station-register
Content-Type: application/json
X-API-Key: ark_xxxxxxxxxxxxx

{
  "station_name": "Nairobi Central Station",
  "station_code": "NBO-CENTRAL",
  "city": "Nairobi",
  "country": "Kenya",
  "latitude": -1.2864,
  "longitude": 36.8172,
  "facilities": ["wifi", "parking", "restaurant", "waiting_room"]
}
```

### 4. API Key System

**Format:**
- API Key: `ark_` + 64 hex characters
- API Secret: `ars_` + 96 hex characters

**Auto-generation:**
- Keys generated automatically when company is approved
- Stored securely in database
- Can be regenerated by admins

**Rate Limiting:**
- 60 requests per minute
- 1,000 requests per hour
- 10,000 requests per day
- Configurable per company

## Integration Flow

### For Railway Companies:

1. **Registration**
   - Visit `/railway-api` page
   - Fill registration form
   - Submit for approval

2. **Approval**
   - Admin reviews application
   - Sets status to 'approved'
   - API keys auto-generated
   - Company receives email notification

3. **Station Registration**
   - Login to dashboard
   - Navigate to Stations tab
   - Add station details
   - Station becomes available on platform

4. **Route Management**
   - Register routes between stations
   - Set pricing in USD and AFC
   - Configure schedules
   - Manage availability

### For Admins:

1. **Review Applications**
   - Access admin dashboard
   - View pending registrations
   - Approve/reject applications

2. **Monitor Usage**
   - View API logs
   - Check rate limits
   - Suspend/reactivate companies

## API Authentication

All API requests require authentication:

```bash
# Header method
Authorization: Bearer ark_xxxxxxxxxxxxx

# Or X-API-Key header
X-API-Key: ark_xxxxxxxxxxxxx
```

## Security Features

1. **Row Level Security**
   - Companies can only access their own data
   - Public can view active stations/routes
   - Admins have full access

2. **API Key Security**
   - Keys are randomly generated
   - Secrets are hashed
   - Can be rotated

3. **Rate Limiting**
   - Prevents abuse
   - Configurable per company
   - Automatic reset

4. **Audit Logging**
   - All API calls logged
   - IP address tracking
   - Request/response logging

## API Endpoints Summary

| Endpoint | Method | Auth | Description |
|----------|--------|------|-------------|
| `/railway-api-register` | POST | None | Register new company |
| `/railway-station-register` | POST | API Key | Register station |
| `/railway-routes` | POST | API Key | Register route |
| `/railway-routes` | GET | API Key | List company routes |
| `/railway-stations` | GET | API Key | List company stations |
